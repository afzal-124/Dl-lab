# Deep Learning Lab Programs

A collection of 8 Deep Learning laboratory experiments implemented using Python as part of the B.E. Computer Science and Engineering (Artificial Intelligence & Machine Learning) curriculum.

This repository covers various concepts of Deep Learning, Machine Learning, Neural Networks, Computer Vision, Natural Language Processing, and Transfer Learning.

## 📚 List of Experiments

| No. | Experiment | Description |
|---|---|---|
| 01 | Word Embeddings using Word2Vec | Generate word embeddings and find similar words. |
| 02 | Deep Neural Network | Implement a DNN for Iris flower classification. |
| 03 | Convolutional Neural Network (CNN) | Classify handwritten digits using the MNIST dataset. |
| 04 | Autoencoder | Perform image compression and reconstruction using an autoencoder. |
| 05 | Text Document Classification | Classify movie reviews using a deep learning model. |
| 06 | LSTM Time Series Forecasting | Predict future values using an LSTM network. |
| 07 | Transfer Learning | Perform image classification using MobileNetV2 and CIFAR-10. |
| 08 | Sentiment Analysis | Classify text reviews as positive or negative. |

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Deep-Learning-Lab.git
```

**Step 2: Open the project folder**

```bash
cd Deep-Learning-Lab
```

**Step 3: Create a virtual environment**

For macOS and Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

For Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

**Step 4: Install the required libraries**

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run each Python program separately.

Example:

```bash
python 01_word_embeddings.py
```

To execute the remaining programs:

```bash
python 02_deep_neural_network.py
```
